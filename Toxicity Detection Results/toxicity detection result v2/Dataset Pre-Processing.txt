Data Preprocessing Techniques Used
Text Cleaning (preprocessing/clean.py):
1. URL removal — regex https?://\S+|www\.\S+
2. @mention removal — regex @\S+
3. Emoji normalization — emoji.demojize() converts emojis to text like :smiling_face:
4. Lowercasing — str.lower()
5. Whitespace normalization — collapse \s+ → single space, strip
6. Duplicate removal — drop_duplicates() (282 removed)
7. Empty text placeholder — empty strings → [no_text]
Applied in order: remove URLs → remove mentions → normalize emojis → lowercase → normalize whitespace.
Tokenization (preprocessing/tokenize.py):
8. Stratified train/val/test split — 80/10/10, stratified on toxic/non-toxic
9. WordPiece tokenization — DistilBERT's AutoTokenizer
10. Padding & truncation — to max_seq_length=128
11. Attention mask — binary mask (1=real, 0=padding)
Label & Data Formatting:
12. Multi-label binary encoding — 6 labels as float32 array
13. HuggingFace Dataset packaging — DatasetDict with input_ids, attention_mask, labels
